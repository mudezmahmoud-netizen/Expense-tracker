# Expense Tracker

## Project Overview
Expense Tracker is a simple web application that helps users manage their daily expenses. Users can add expenses, delete them, filter expenses by category, and calculate their total spending.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage
- Jest
- Git and GitHub

## Features
- Add expenses with descriptions, amounts, and categories.
- Delete expenses.
- Filter expenses by category.
- Calculate total expenses.
- Save expenses using localStorage.
- Load saved expenses automatically.
- Responsive user interface.

## JavaScript Concepts
- Object-Oriented Programming (OOP)
- Classes and objects
- Destructuring
- Array methods: map, filter, reduce
- Spread and rest operators
- LocalStorage

## Testing
Jest is used to test:
- Adding expenses
- Removing expenses
- Calculating total expenses
- Filtering expenses by category

## How to Run
1. Clone the repository.
2. Open the project in VS Code.
3. Run the application using Live Server.
4. Run tests using `npm test`.
